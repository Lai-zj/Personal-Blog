# 数理统计与数据分析系列总目录

参考教材：John A. Rice 著，田金方 译，谢邦昌 审校，*数理统计与数据分析*（原书第 3 版），机械工业出版社，2012（"统计学精品译丛"）。

本系列按教材章节顺序编排：第 1～6 章为概率论基础，第 7～9 章为统计推断，第 10～13 章为数据分析方法，第 14 章为线性最小二乘。每篇对应教材的一节或数节。标题格式统一为：

```
[数理统计与数据分析]-[分类]-NN标题
```

其中 `NN` 是分类内的篇号。整个系列计划 38 篇，目前已完成 8 篇，其余按本目录顺序补写。

## 学习路线

- **概率论基础（第 1～6 章）**：一、概率 → 二、随机变量 → 三、联合分布 → 四、期望 → 五、极限定理 → 六、正态分布的导出分布；
- **统计推断（第 7～9 章）**：七、抽样调查 → 八、参数估计和概率分布拟合 → 九、假设检验和拟合优度评估；
- **数据分析（第 10～13 章）**：十、数据汇总 → 十一、两样本比较 → 十二、方差分析 → 十三、分类数据分析；
- **回归与平滑（第 14 章）**：十四、线性最小二乘。
