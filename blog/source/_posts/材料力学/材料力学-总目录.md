# 材料力学系列总目录

参考教材：孙训方、方孝淑、关来泰 编，*材料力学*（第6版）（Ⅰ、Ⅱ），高等教育出版社，2019。

本系列按教材章节顺序编排：第Ⅰ册为基础篇（第1～9章），第Ⅱ册为提高篇（第1～7章）。分类编号跨两册连续编排（一～十六），以便侧栏按学习顺序排列。标题格式统一为：

```
[材料力学]-[分类]-NN标题
```

其中 `NN` 是分类内的篇号。整个系列计划 32 篇（第Ⅰ册 20 篇、第Ⅱ册 11 篇、附录 1 篇），目前已完成 27 篇，其余按本目录顺序补写。

## 学习路线

- **第Ⅰ册（基础）**：一、绪论及基本概念 → 二、轴向拉伸和压缩 → 三、扭转 → 四、弯曲应力 → 五、梁弯曲时的位移 → 六、简单的超静定问题 → 七、应力状态和强度理论 → 八、组合变形及连接部分的计算 → 九、压杆稳定；
- **第Ⅱ册（提高）**：十、弯曲问题的进一步研究 → 十一、考虑材料塑性的极限分析 → 十二、能量法 → 十三、压杆稳定问题的进一步研究 → 十四、应变分析·电阻应变计法基础 → 十五、动荷载·交变应力 → 十六、材料力学性能的进一步研究；
- **附录**：截面的几何性质。
